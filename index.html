🔐 금융 금고

금융 정보만 별도 암호화해 보호해. 다른 인생관리 사이트 기능은 그대로 사용할 수 있어.

비밀번호를 잊으면 암호화된 금융 데이터를 복구할 수 없어. 설정 전 백업을 권장해. 이 잠금은 Face ID가 아닌 비밀번호 방식이야.

🏦 6개 금융기관

금융기관은 모두 관리할 수 있어. 실제 계좌 자동 조회는 이용기관 승인 및 안전한 서버 연결이 필요해.

상태: 6곳 모두 API 미연결 · 자동 동기화 비활성화 · 잔액은 수동 입력값

💰 나의 자산

현재는 개인용 오프라인 자산관리야. 실제 은행·증권사 자동 조회는 공식 API 이용 승인이 필요해서 아직 연결되지 않았어. 숫자는 직접 등록한 자료로 계산돼.

🏦 계좌 · 자산 · 부채

현금, 예금, 적금, 주식, 연금, 전세보증금, 대출을 각각 등록해 줘. 계좌번호나 비밀번호는 적지 마.

📒 월별 가계부

📥 금융자료 가져오기 · V3.2

신한은행 · 국민은행 · 카카오뱅크 · 새마을금고 · NH투자증권(나무) · 신한투자증권 자료를 위한 공통 CSV 가져오기야. 공식 계좌 자동 연결은 아직 아니며, 파일 형식에 따라 열을 직접 지정해야 해. 엑셀(.xlsx)은 은행/증권사에서 CSV UTF-8로 저장한 후 선택해 줘.

계좌번호·주민번호 등 개인정보가 포함된 파일은 업로드하지 않는 것을 권장해. 가져오기 전에 불필요한 열을 삭제해 줘.

Firebase 설정을 확인하는 중…

로그인 정보는 Firebase Authentication에서 관리해. 사이트에 비밀번호를 별도로 저장하지 않아.

처음 선택한 뒤에는 자동 동기화돼. 같은 기록을 두 기기에서 동시에 수정하면 마지막 저장이 우선할 수 있어.

금융 금고 및 금융 데이터는 보안을 위해 클라우드에 올리지 않아. 연차 계산기의 수동 사용 내역은 동기화돼.

데이터 백업 · 복원

기록은 기기에 저장되고, 로그인 후 동기화를 시작하면 금융 데이터를 제외한 기록이 클라우드에도 저장돼. 업데이트 전에는 반드시 JSON 백업을 만들어 줘.

복원하면 현재 기록이 백업 내용으로 교체돼. 먼저 기존 데이터를 백업해 줘.
