# 인생관리 사이트 V5.0 — 설치 안내

## 0. 가장 먼저 아이폰 기록 백업
기존 V4.9가 저장된 **아이폰의 기존 사이트**에서 `분석 → JSON 백업 파일 만들기`를 눌러 파일 앱에 보관해.
가능하면 아이폰에서 V5.0 사이트에 접속한 뒤, **기존 V4.9 JSON 백업을 복원**하고 `분석 → JSON 백업 파일 만들기`를 다시 실행해. 이 두 번째 백업에는 연차 계산기의 수동 사용 내역도 포함돼. 기존 V4.9 백업에는 수동 연차 기록이 포함되지 않을 수 있어.

## 1. Firebase 설정
1. https://console.firebase.google.com/ 에서 프로젝트 생성. Google Analytics는 필요 없다면 끌 수 있어.
2. `빌드 → Authentication → 시작하기 → Sign-in method`에서 **이메일/비밀번호** 사용 설정.
3. `빌드 → Firestore Database → 데이터베이스 만들기`에서 프로덕션 모드 선택. 위치는 가까운 리전을 선택하되 생성 후 변경이 어려우니 확인해.
4. Firestore `규칙` 탭에 `firestore.rules`의 전체 내용을 붙여넣고 **게시**. (로그인한 사용자 본인 문서만 접근 가능)
5. `프로젝트 설정 → 일반 → 내 앱 → 웹 앱 추가`에서 Firebase 웹 앱 등록. 표시된 `firebaseConfig` 값을 `firebase-config.js`에 복사해.
6. `Authentication → Settings → Authorized domains`에 **YOURNAME.github.io**를 추가해. (이메일/비밀번호 로그인도 도메인 설정을 확인해 두면 좋아.)

**주의:** Firebase `apiKey`는 웹 설정값이며 서버 관리자 비밀키가 아니야. 그래도 Firebase 보안 규칙은 반드시 적용해야 해. 절대로 서비스 계정 비밀키를 GitHub에 올리지 마.

## 2. GitHub Pages
1. GitHub에 새 저장소(예: `life-manager`) 생성. 민감한 JSON 백업 파일은 업로드하지 마.
2. 이 ZIP 안의 `index.html`, `firebase-config.js`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`를 저장소 최상위에 업로드. `firestore.rules`와 README는 참고용으로 함께 올려도 돼.
3. `Settings → Pages → Build and deployment → Deploy from a branch`에서 `main` / `/(root)` 선택 후 Save.
4. 공개 주소: `https://YOURNAME.github.io/life-manager/` (저장소 이름에 따라 달라져).

## 3. 아이폰 ↔ PC 이전 및 동기화
1. **아이폰의 기존 V4.9 사이트**에서 JSON 백업을 먼저 만들어 안전하게 보관.
2. 새 V5.0 GitHub Pages 주소를 아이폰 Safari에서 열어 `분석 → JSON 백업 파일 복원`으로 기존 기록을 가져와.
3. 같은 `분석` 탭의 `기기 간 동기화`에서 회원가입 또는 로그인.
4. `이 기기 기록을 클라우드에 올리기` 선택. 이때 올릴 데이터가 맞는지 먼저 확인해.
5. 컴퓨터에서 같은 URL을 열고 같은 계정으로 로그인한 뒤 `클라우드 기록 가져오기` 선택.
6. 이후 두 기기에서 저장할 때 자동으로 클라우드에 반영돼. **동시에 두 기기에서 수정하는 것은 피하는 게 안전해.**
7. 아이폰 Safari의 공유 버튼 → `홈 화면에 추가`를 누르면 앱처럼 실행 가능해. 홈 화면 앱은 Safari와 저장 공간이 분리될 수 있으므로 로그인 후 `클라우드 기록 가져오기`로 연결해.

## 주의사항
- 금융 금고·금융 거래/자산 데이터는 클라우드로 전송하지 않아. 금융 자료는 각 기기에서 따로 관리하고 암호화된 금융 금고 백업을 안전하게 보관해.
- 일정·감정·일기·글·할 일은 **Firestore에 저장되지만 별도 종단 간 암호화는 적용되지 않아**. 민감한 내용은 신중하게 입력해.
- Firebase 무료 한도/서비스 정책에 따라 비용이 발생할 수 있어. 사용량 알림을 설정해.
- 이 버전은 간단한 마지막 저장 우선 방식이야. 오프라인 상태나 두 기기 동시 수정에서 충돌할 수 있으니 중요한 수정 전후에는 JSON 백업을 보관해.
- 기존 로컬 저장소는 URL/브라우저/홈 화면 앱별로 달라. 사이트를 게시했다고 자동으로 이전되지는 않아.
- 배포 후 로그인과 동기화를 **실제 두 기기에서 테스트해야 해**.
